# Setting Inbound Rule
---
- First press the Windows key and type in "wf.msc" which should open windows defender firewall with advanced security 

- Find and click the button that says "new inbound rule"

- Select port
- Select tcp
- Select specific local port and type "1883,8088"
- Allow the connection
- Give it a name like ignition
